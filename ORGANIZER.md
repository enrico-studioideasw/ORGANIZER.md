# Project Memory Organizer

This repository is a public laboratory for explicit, maintained project
memory in AI-assisted software development.

Read in this order:

1. `shared/PROJECT_MEMORY.md` for confirmed principles and shared decisions.
2. The relevant file under `agents/` for observations attributable to one
   assistant.
3. The material under `esempi/` for concrete, project-specific examples.

## Authority

- Project files and current observations remain the primary evidence.
- `shared/` contains knowledge accepted for reuse across assistants.
- `agents/` contains attributed observations, hypotheses and lessons. An
  agent-specific note is not automatically a shared decision.
- Enrico retains authority over architectural decisions and promotion of
  knowledge from an agent diary into shared memory.

## Public/private boundary

This repository contains only material suitable for public inspection and
replication. Passwords, tokens, private keys, internal addresses and detailed
operational access procedures belong in protected local memory, never here.

## Participants

- `agents/zeno/`: development analysis, project continuity and methodological
  observations.
- `agents/zeno-malvagio/`: infrastructure experiments and observations from
  the "Covo", published only after removing private operational details.
