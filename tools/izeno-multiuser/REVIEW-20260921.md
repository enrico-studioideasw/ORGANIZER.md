# Independent installation review — 21 September 2026

Zeno Aziendale installed the first package in a separate environment and
returned a reproducible correction set. The review found several contracts
that syntax checks alone had not exercised:

- the initial schema omitted `last_activity` and the `inactive` close reason
  already used by the worker;
- limiting participation with a count followed by an insert was subject to an
  admission race;
- a stale heartbeat could interfere with session expiration;
- in-memory presence counters required idempotent reconstruction from the
  database after restart;
- socket closure did not prove that a request had emitted both a final answer
  and a completion marker;
- interrupted work must be marked for inspection rather than replayed
  automatically;
- spontaneous messages require an owner once transcripts are filtered;
- a corrupt or non-resumable saved model thread must remain an explicit
  failure, not silently become a new identity.

The revised reference implementation includes these corrections, a database
advisory lock preventing duplicate workers, six isolated daemon tests and a
repeatable migration test against a temporary MariaDB database.

The review also preserved the central distinction of the experiment:
transcripts are separate, while the model context is shared. This is deliberate
and places a duty of discernment on the resident agent; it is not cryptographic
or process-level isolation between conversations.
